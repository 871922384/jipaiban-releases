让智能体接住班表

极排班的公开技能和托管 MCP 是同一个产品入口：先确认身份，再查看、补充和分享排班。

公开 Agent 技能

支持 skills 或远程 MCP 的客户端，都可以从同一份技能正文开始。Guest 先试用；需要医院数据时，再由用户在连接页完成配对。

打开接入页 ↗查看技能

三步开始

  1. 导入技能复制 skills/jipaiban/ 到客户端的 skills 目录。
  2. 添加 MCPhttps://jipaiban.junshian.cn/mcp
  3. 确认身份initialize → tools/list → whoami
不要把 token 写进 URL。没有返回的数据就明确说没有数据，不猜测班次。
